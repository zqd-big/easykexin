第十九题：【软件认证】带WriteBuffer的内存读写操作
WriteBuffer 是位于处理器与主存之间，一种非常小的 FIFO 高速缓存，其目的是解决主存与处理器之间速度不匹配的问题，提升处理性能。

现给定 WriteBuffer 缓存请求个数的上限为 bufferCap，并给定一组操作 operations，operations[i] = [操作码op, para1, para2, para3]，以及初始的主存数据 data，请按输入顺序执行操作，并返回最终的内存结果。
内存操作如下：

内存写： op = 1，operations[i] = [1, 偏移para1, 长度para2, 内容para3]，意图是：在主存 data 中从偏移为 para1 的地址开始，将连续 para2 个字节的内容都写为 para3。规则如下：

按每 8 字节分解为多个写请求（最后一个写请求可能小于 8 字节），所有分解后的写请求按地址从小到大依次放入缓存。

如果缓存请求个数达到上限 bufferCap，则采用 FIFO（先进先出）的方式从缓存中取出最早的写请求，把请求的内容写入主存；然后再把新请求再放入缓存中。

内存读： op = 2，operations[i] = [2, 偏移para1, 长度para2, 0]。从偏移为 para1 的地址开始，连续读出长度 para2 字节的数据。

当读的数据范围在缓存中有写请求时，需按照 FIFO 模式，先将涉及的缓存写请求全部写入主存中。

注意：FIFO 模式不可以从缓存中间直接取出写请求，涉及的写请求及之前的所有写请求都需要取出并写入主存。

内存同步： op = 3，operations[i] = [3, 0, 0, 0]，将缓存中的所有写请求都取出来并写入主存中。

解答要求
时间限制: C/C++ 1000ms, 其他语言: 2000ms
内存限制: C/C++ 256MB, 其他语言: 512MB

输入
第一个参数是 bufferCap， 4 <= bufferCap <= 32
第二个参数是 operations ， 1 <= operations.length <= 1024
1 <= op <= 3；para1 在 data 地址范围之内；0 <= para2 <= bufferCap * 8 （当op为读或写时，para2 >= 1）； 0 <= para3 <= 255
第三个参数是主存 data，是16进制的字符串（字符为[0-9A-F]，字母为大写），如"1FA082"，每两个字符表示1个字节；
2 <= data.length <= 30000 ，且 data.length 为 2 的整数倍
题目保证读写地址都在 data 范围之内

输出
经过内存操作后主存 data 中的数据内容，16 进制的字符串（字符为[0-9A-F]，字母为大写）

样例1
输入：

Plaintext
4
[[1, 1, 3, 255], [3, 0, 0, 0], [1, 2, 11, 120], [2, 11, 1, 0]]
"1DA08200000000000000901ABCDEF00"
输出：

Plaintext
"1DFF7878787878787878787878EF00"
解释：
[1, 1, 3, 255]: 写内存操作，从偏移为 1 的地址开始，将连续 3 个字节的内容都写为 0xFF。仅生成一个写请求在缓存中，此时主存数据保持不变。
[3, 0, 0, 0]: 内存同步操作，所有缓存的请求都写入到主存中，写完后主存数据为 1DFFFFFF000000000000901ABCDEF00。
[1, 2, 11, 120]: 写内存操作，从偏移为 2 的地址开始，将连续 11 个字节的内容都写为 0x78。按8字节拆分成 2 个写请求，存入缓存中，此时主存数据保持不变。
[2, 11, 1, 0]: 读内存操作，从偏移为 11 的地址开始，连续读出长度 1 字节的数据。读数据地址在缓存中的写请求 1 的数据范围内；按FIFO的特点，缓存中的写请求 1 及之前的请求都需要从缓存中取出并写入主存中。操作后主存数据为 1DFF7878787878787878787878EF00

某代码仓配置了文件修改评审的Committer信息。现有一个MR（Merge Request）修改了一批文件 files，files[i] 表示允许评审文件 i 的 Committer 编号列表。每个文件需要至少一名Committer评审才能合入，每名Committer可以评审多个文件。

请计算并返回该MR最少需要多少名Committer，才能完成所有修改文件的评审？

输入
0 < files.length（文件个数） <= 12
0 < files[i].length <= 10， 0 <= files[i][j] < 10， files[i] 中元素（Committer 编号）各不相同

输出
一个整数，表示最少Committer个数

输入：

Plaintext
[[0], [5, 2, 3], [0, 5]]

Plaintext

其他组合需要更多的Committer。
因此返回 2。
